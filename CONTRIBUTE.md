# Contributing

Thanks for taking an interest in this project.

## Simple Contribution Workflow

1. Fork the repository.
2. Create a new branch.
3. Make a focused change.
4. Test the notebook or Flask application.
5. Update `CHANGELOG.md` when the change affects project behavior.
6. Submit a pull request with a clear description.

## Good Contribution Ideas

- Improve the CPU training configuration.
- Add useful evaluation visualizations.
- Improve the Flask interface.
- Fix documentation issues.
- Add small, practical examples for text classification.

## Project Guidelines

- Keep the repository structure simple.
- Do not add a `src/` directory.
- Avoid unnecessary preprocessing/module scripts.
- Prefer clear notebook cells for experimentation.
- Keep dependencies reasonable for CPU users.
- Do not commit large model checkpoints or dataset files.
